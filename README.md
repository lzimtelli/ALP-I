# ALP-I

**Algoritmos e Lógica de Programação 1**

### Estrutura de Atividades

O repositório está organizado de acordo com as listas de exercícios e tópicos estudados durante o início da disciplina:

* **Lista Fluxograma:** Exercícios focados na lógica inicial de programação, resolução de problemas e estruturação visual de algoritmos.
* **Lista 2:** Introdução à programação em C, variáveis, tipos de dados e operadores básicos.
* **Lista 3:** Estruturas de controle de fluxo, como condicionais (if, else, switch).
* **Lista 4:** Estruturas de repetição (for, while, do-while) aplicadas na resolução de problemas lógicos.
